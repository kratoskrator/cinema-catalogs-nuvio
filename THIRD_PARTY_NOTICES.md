Cinema Catalogs is an independent catalog add-on. It is not affiliated with Nuvio, Filmix, Seasonvar, DiziBOX, DiziYou, IMDb or TMDB.

The runtime consists of static JSON. Build and collection tools use only Node.js built-ins. The website parsers were independently implemented; no site scripts, video content, credentials or third-party runtime libraries are included.

Source listing metadata was collected from the public FilmixTV metadata API, Seasonvar, DiziBOX and DiziYou. Posters are public image links, with official Nuvio/TMDB artwork preferred. Source titles, years, links, identity mappings and collection timestamps are retained as factual provenance. Full source HTML and metadata caches are excluded from the distributed archive.

The public official Nuvio catalog at https://catalog.nuvio.tv/ was used to verify title/year/type and IMDb/TMDB identity. Existing Nuvio metadata providers supply full title details and episodes at use time.

- Nuvio TV metadata fallback: https://github.com/NuvioMedia/NuvioTVSmart/blob/main/js/ui/screens/detail/metaDetailsScreenMethods-03-load-detail.js

- Stremio addon manifest protocol: https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/api/responses/manifest.md
